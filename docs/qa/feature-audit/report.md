# Feature, role and navigation audit

This pass audits the implemented application. It does not add unspecified business domains or claim every workflow has been certified on every device. The [impact map](plan.md) records scope and ownership.

## Changes

- Web/Tauri navigation now groups every route, including single-item groups and individual Settings pages, into collapsible sections. Group and row spacing increased using existing tokens. Native More uses corresponding grouped sections.
- The sidebar collapse control is above the workspace selector. Pointer/keyboard resizing and collapsed-width restoration remain intact.
- Connectivity is in the header. Restricted roles can see status without following a link to a device page they cannot access; native status remains in its header strip.
- Accounting navigation now reuses the existing business-wide accounting capability. Store/warehouse-scoped managers retain their permitted reports without a misleading Accounting entry. Server permissions are unchanged.
- Native viewers and custom roles without reports permission receive the workspace-ready screen instead of making a forbidden dashboard request.
- Cash/receipt warehouse selection recovers when authorized locations load or a selected warehouse becomes inactive. It no longer keeps an unavailable warehouse ID. Native already used this fallback.
- Fixed a reproduced cart-loss bug: clicking Overview as a cashier redirected to POS but unmounted the existing cart. Web/Tauri and native now keep visited checkout mounted across cashier and platform-overview navigation. Normal authorization/account boundaries still apply; this is not durable cart persistence across reload/logout.

No database migrations, backend calculations, API contracts, permission grants, external payment integrations or new dependencies were changed.

## Limits

Windows cannot be built or run on this macOS host with the required Windows toolchain. iOS exports are distinct from an iOS Simulator/native build; full Xcode is unavailable. Hardware scanners/printers, signed releases, physical-device offline recovery and assistive-technology qualification remain manual release work.

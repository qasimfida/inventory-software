Argument names the module. Same method as phase 6: characterization tests for financial and permission behavior first, then redesign on web, desktop and mobile.

- payables: collection, supplier details, amounts, balances, settlement, credit commands, history, filters, pending/error states. Make amounts easy to compare.

- reports: report selection, date, location and warehouse filters, metrics, charts, tables, exports, partial results, empty/loading/error.

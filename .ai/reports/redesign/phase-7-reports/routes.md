## State review

- Populated, empty, low-stock filtering, seven categories, export, error/recovery: Chrome mock, light/dark, widths390/844/1024/1280/1440/1920. No document horizontal overflow or page exceptions. Header/notes are responsive; exact columns scroll inside a named keyboard-accessible region on narrow screens.
- Initial/interaction loading, disabled Run/export/pagination, invalid date range, denied access and native deferred opening retain original lifecycles. Unit tests cover no unauthorized request, no premature draft fetch, invalid range and export errors.
- No free-text search, report sorting, chart series, arbitrary location filtering, editing, destructive commands, confirmation dialogs or success mutations exist here. Do not fabricate these states. Warehouse scope remains authoritative on the backend.
- No new chart: generic measure rows mix incompatible units and currencies, not a coherent time series. Exact table remains the primary representation. Existing dashboard ChartPresentation/preferences are untouched.
- No persistent cache, additional request, transaction or money arithmetic introduced. In-memory ResourceModel/usePageCollection behavior unchanged. No claim that cached evidence is newly confirmed.
- Native web-adapter tests/exports do not qualify a physical device. Real data reconciliation, large data, server denied access, offline/session expiry and comprehensive assistive-technology testing remain outstanding.

- 16 automated tests: exact large positive/negative and zero outstanding, payment/cash/purchase permissions, full-credit cutoff, stable credit/settlement retries, viewer no-write controls, GET-only error retry, populated/empty detail evidence on web/native adapters.
- Browser six widths × two themes: collection, supplier filter/reset, invoice details, payment and credit command drawers. At 1440px: empty invoices, failed reads/retry, recovery to normal. Commands opened/closed without submission.
- Retained server-only 25-row list/history paging and latest-100 return limit. Mock list is small; no claim of large-data or server pagination qualification.
- Unsupported: no server search/date/status filters, list/grid switch, payable export or independent supplier-profile endpoint in this screen's contracts. None invented for visual consistency.
- Financial success, server denial/rollback/concurrent mutation, real offline failures and native device behavior remain unqualified. This screen requires online authority; no offline settlement added.

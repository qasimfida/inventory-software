# Proposed GitHub Actions release checks — approval pending

No `.github/workflows` file has been created. This is the concrete job design for approval, not an installed pipeline. Resolve the documented regression failures before treating any job as a release gate.

## Triggers and isolation

Pull requests and pushes to the protected main branch; cancel superseded runs for the same ref. Read-only repository permissions, no production credentials, no production seed accounts. Pin checkout/setup/artifact actions to reviewed commit SHAs when implementing. Use Node 24/npm 11.6.2 and `npm ci`. Cache npm downloads, not mutable build outputs or databases. Keep signing jobs separate, protected and unavailable to untrusted PRs.

Windows/macOS clean install/upgrade; real API authentication and scoped workflows; printer/scanner; deep links; vault interruption/restart; expired grants and sync conflicts; VoiceOver/NVDA/TalkBack. Record artifact hash, hardware/OS, role and actual results. Signing, deployment and automatic updates are not authorized by approving this test workflow.
